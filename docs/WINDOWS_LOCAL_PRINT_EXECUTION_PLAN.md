## 1. 交付目标

用户在 Windows 电脑打开 WMS，首次点击“安装打印组件”，完成安装、自启动及本站信任设置。之后直接在 WMS 选择该电脑已连接的打印机，点击打印即可提交到本机打印队列，不打开 PDF，不重复弹出打印确认窗口。

标签使用 Product IPN QR Code Label，基准尺寸 50 × 30 mm。商品详情、库存详情及对应列表均支持单件、批量、多份打印。保留主动下载 PDF 的备用入口。

本期不包含手机直接驱动打印机、扫码后自动打印、服务器集中打印，以及全部历史标签功能的重构。

```text
用户 WMS 页面 ──提交标签请求──> WMS 后端生成 PDF
       │                              │
       └────凭当前用户权限获取文件─────┘
```

## 4. 分阶段执行任务

### 阶段一：最小实机验证与组件定版

执行顺序：

1. 在测试 Windows 上安装厂商驱动，确认系统测试页能打印。
2. 安装候选组件并记录版本、安装来源、文件校验值及自启动方式。
3. 从实际 WMS HTTPS 站点验证安全连接和打印机枚举。
4. 用用户提供的 50 × 30 mm PDF 打印一张，确认中文、方向、纸张和二维码。
5. 配置受信任签名，验证首次授权后再次打印不反复弹确认。
6. 重启 Windows、重新登录后重复连接及打印。
7. 确认许可、安装包分发方式、证书维护责任及费用，固定支持版本。

交付物：兼容性记录、组件版本清单、信任部署方案、实物打印和扫码结果。

完成条件：目标 Windows 机型可枚举、可出纸、可扫码，签名和重启流程成立。未通过则先解决兼容性，不继续围绕未验证组件扩大实现。

### 阶段二：模板和服务端任务接口

1. 将商品 IPN 标签设为商品/库存本地打印的唯一业务模板，前端展示中文名称“商品 IPN 标签”。
2. 按模型类型查找模板，禁止硬编码当前数据库 ID 7、8；缺失、禁用或重复配置时明确报错。
3. 提供可重复执行的部署配置步骤，停用已知旧示例模板，保留备份、恢复方法和库位标签。不得按名称模糊匹配批量删除用户模板。
4. 复用现有标签生成权限、商品 IPN 校验、份数及批量限制，输出继续使用现有 PDF。
5. 增加本地打印任务记录，保存任务 ID、请求去重键、用户、商品/库存引用、模板、文件摘要、份数、目标队列、时间和状态。优先复用 DataOutput，不另建第二套 PDF 生成流程。
6. 增加获准操作的签名接口，按登录身份校验任务归属、可打印对象、文件摘要、目标、纸张参数和有效期。
7. 枚举打印机属于独立允许操作；打印操作必须绑定任务。不签任意调用，不开放组件文件、串口或任意网络功能。
8. 增加状态上报、查询和显式补打接口；补打创建新任务并关联原任务。

拟定接口职责（路由命名在实现时按项目风格确定）：创建任务、查询任务、获取签名证书、签署允许的请求、上报提交结果、创建补打任务。私钥不通过任何接口返回。

交付物：任务接口、数据库变更（如需要）、模板配置步骤、受限制签名服务及接口测试。

完成条件：跨账号访问和任意签名被拒绝；同一请求重试返回同一任务；份数不重复展开；模板无需依赖固定 ID。

### 阶段三：前端本机连接与打印弹窗

1. 新增本地打印客户端封装，统一连接、断开、版本检测、枚举、发送及错误分类；避免多个弹窗重复创建连接。
2. 打印弹窗固定展示“商品 IPN 标签 · 50 × 30 mm”，取消模板和服务端机器选择。
3. 未连接时显示“安装打印组件”“重新检测”“下载 PDF”。检测失败区分未运行、拒绝信任、浏览器限制、连接超时及版本不支持。
4. 已连接时显示本机打印机列表、刷新按钮、每件份数、总张数、打印按钮。
5. 用户明确选择打印机后再允许发送；选择按 WMS 站点和当前浏览器保存，每次连接重新验证队列存在。失效后不得自动切换另一台打印机。
6. 本地打印模式接管 PDF 生成完成事件，禁止自动 window.open；普通报告和主动 PDF 下载保持现有路径。
7. 在已登录网页内获取 PDF 并传输给组件，不向组件泄露登录 Cookie，不依赖组件直接访问受登录保护的地址。
8. 后端 PDF 已按份数展开页面，组件 copies 固定为 1。按验证后的 50 × 30 mm、实际大小和方向提交。
9. 提交中禁用重复点击；显示“已提交到本机打印队列”，没有硬件回执时不显示“已出纸”。
10. 退出登录中止尚未发送的流程；切换用户后不可继续旧用户任务。

交付物：本地打印弹窗、连接管理、默认队列保存、PDF 完成回调、异常提示和组件测试。

完成条件：正常打印无需打开 PDF；换电脑获取对应队列；报告打印无回归；安装失败仍可主动下载 PDF。

### 阶段四：安装、信任和运维交付

1. WMS 增加 Windows 安装入口，提供经过验证的下载链接/安装包、版本和安装步骤。
2. 引导用户执行安装、允许登录自启、完成本站信任、返回网页检测；网页不尝试绕过 Windows 安装确认。
3. 组件运行在当前登录用户会话，保证可见该用户的共享打印队列。锁屏、注销等场景按实测行为写清。
4. 将签名私钥通过部署秘密配置注入实际执行签名的服务；记录更新、到期提醒、轮换和撤销步骤。
5. 提供管理员诊断步骤：Windows 测试页、组件状态、证书、队列、纸张配置、任务记录。
6. 制定升级兼容范围；版本不满足要求时提示升级，不引导关闭安全校验。

交付物：安装入口、用户安装说明、管理员部署说明、证书维护步骤。

完成条件：新用户仅按文档即可安装并完成首次打印；重新登录 Windows 后无需手动启动组件。

### 阶段五：回归与试点上线

1. 完成下表自动化及真机验收，记录测试环境、结果和证据。
2. 先向一个仓库工位启用本地打印，验证正常班次的单件、批量和补打。
3. 确认份数、纸张、重复提交和断网行为无问题，再推广到其他 Windows 工位。
4. 保存前一版应用及部署配置；通过功能开关关闭本地打印即可回退 PDF 路径。

交付物：验收记录、发布说明、回退步骤及用户操作说明。

完成条件：自动化检查通过、Windows 实物扫码通过、试点通过；明确区分排队成功与实际出纸。

## 5. 任务状态与重复打印控制

建议状态：生成中、待提交、提交中、已提交队列、失败、结果待确认。只有设备提供可靠回执时才扩展“已打印”。客户端上报仅表示客户端观察结果，不作为设备已出纸的证明。

| 情况 | 必须行为 |
| --- | --- |
| 连点打印 | 前端防连点，同时复用请求去重键 |
| PDF 生成失败 | 未发送打印，展示错误，允许重新生成 |
| 提交前组件断开 | 保留任务，连接恢复后由用户继续 |
| 发送后连接丢失或页面崩溃 | 标记结果待确认，不自动再次发送 |
| 刷新、另一标签页重试同任务 | 服务端原子认领发送尝试；已认领或状态不明不得自动重复发送 |
| 缺纸、暂停、脱机 | 显示可获得的队列状态，指导检查系统打印队列 |
| 用户确认补打 | 创建新任务，记录原任务及操作者 |

数据库提交与 Windows 打印队列无法组成同一事务，不承诺跨故障的“恰好打印一次”。认领超时不代表未发送，不能直接重新派发；结果不确定时采用人工确认和显式补打。

| A12 | 功能关闭与回退 | PDF 打印可用，未发送任务不被意外执行 |

自动化重点：模板解析、权限、签名操作白名单、参数/文件绑定、请求去重、状态流转、份数、输出完成回调和异常恢复。真实驱动、证书信任、硬件状态、纸张及扫码必须真机验证。

## 8. 排期与责任

以下为单名熟悉项目的开发者工作量估算，不是承诺交付日期；不包含采购、证书办理、设备等待及厂商驱动问题处理。

| 阶段 | 估算 | 主要责任 |
| --- | --- | --- |
| 组件实机验证 | 0.5–1.5 人日 | 开发 + 提供设备的管理员 |
| 服务端任务与签名 | 1.5–3 人日 | 开发 |
| 前端交互与组件集成 | 1.5–3 人日 | 开发 |

## 9. 发布与回退

上线前备份涉及的模板配置和数据库；如有迁移，先验证迁移及前一版应用的兼容性。默认关闭本地打印功能，完成签名部署和指定试点后开启。

回退时先关闭本地打印入口，保留显式 PDF 下载；不删除打印任务记录，不自动重放未确认任务。保留打印组件不影响 PDF 使用；需要卸载时由 Windows 管理员处理。数据库回退不能通过删除业务数据实现。

旧模板只在确有业务需要时重新启用，不因打印组件回退而自动恢复全部示例标签。
