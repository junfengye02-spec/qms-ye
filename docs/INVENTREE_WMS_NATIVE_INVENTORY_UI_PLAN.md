# 原生库存页面增量改造计划（精简版）

状态：已完成原生增量接入及独立预览验收。日期：2026-09-07。

用户要求：在截图的原生库存页面上增加功能，简洁为主；查询沿用原有搜索框，统计等能力轻量呈现。

## 默认页面

入口保持 `/web/stock/location/index/stock-items`。保留原生导航、库存地点／库存项侧栏、面包屑、工具栏、表格、列设置和分页。首屏还是现在的库存表，不新增业务标签工作区、常驻筛选表单或统计大卡片。

## 功能如何增加

| 功能 | 精简方案 |
| --- | --- |
| 查询 | 沿用右上角一个搜索框，支持设备ID、名称、项目号、品牌、型号等关键字。精确项目、分类、地点和冻结状态等条件放进原生筛选菜单，需要时才展开；搜索和筛选共同作用于列表、统计和导出。 |
| 表格 | 原表补充所需字段，IPN 显示为设备ID，Batch Code 显示为项目号。默认只放日常需要的列，品牌、型号、规格、备注、变动时间等通过原有列设置选择。保留原有行操作。 |
| 统计 | 表格旁增加一行简短小计，例如“设备 2 种 · 库存 5 count、8 m”；需要的冻结／可用数量在同行或对应表格列展示。统计全部匹配结果，不只统计当前页；不同单位分别列出。 |
| 汇总 | 在工具栏菜单提供“按设备汇总”，仍用原生表格显示；明细默认保持现状。汇总行不能被当成单个实际库存项操作。 |
| 地点 | 沿用原生地点树；选中地点后，用原有筛选入口切换“含下级／仅本地点”。明细显示实际地点，统计和导出跟随相同范围。 |
| 期间记录 | 从本页工具栏菜单打开原生风格弹窗，沿用搜索框和表格；增加必要的入／出库方向、日期范围，数量小计仍只用一行。 |
| 设备资料 | 从本页工具栏菜单打开原生风格资料列表及新建／编辑弹窗，沿用搜索、表格和表单。 |
| 导入 | 在原有导出按钮旁新增独立“导入”按钮；点击后选择设备资料导入或库存盘点导入，再打开上传、预览、确认弹窗；错误和差额按行显示。 |
| 导出 | 沿用右上角下载入口，导出当前筛选下的全部结果，明细与汇总分别处理。 |

扫码和审批继续沿用现有入口。上一轮已经完成的后台校验、项目隔离、冻结保护和导入事务等能力复用；原生页面验收后收回扫码页面的重复管理界面。

单位保留原生校验，不维护中文业务单位。采购、销售、生产、调拨等范围不扩展。

## 实施顺序

1. 优先完成原生表格字段、单一搜索框、原生筛选菜单及一行统计，检查首屏是否仍然简洁。
2. 接入工具栏菜单中的汇总、期间记录、设备资料，以及相邻的导入／导出按钮，全部复用原生视觉与交互组件。
3. 在截图 URL 和具体地点页实际验收，随后整理扫码页重复入口并更新预览。

## 验收重点

- 默认页面仍是原生库存项表格，查询使用原有搜索框，新增操作按需展开。
- 搜索项目号／设备ID等能定位库存；列表、数量小计和导出使用同一查询范围。
- 原有列显隐、分页、行选择、详情及库存操作保持可用。
- 父地点直属5、子地点3：含下级8，仅本地点5。
- 日期记录只统计正式成功入出库，分单位合计；盘点10改8、冻结保护、任务重试等规则正确。
- 桌面和手机检查，以及本次改动所需的前端检查和后端回归。
