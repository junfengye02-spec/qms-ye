# InvenTree WMS 库存管理需求说明书

> 文档状态：需求确认版  
> 编制日期：2026-09-07  
> 适用范围：设备主档、库存管理、扫码入库、扫码出库、审批、统计、导入导出和库存审计

## 1. 建设目标

本次开发需要将现有 InvenTree WMS 的设备和库存业务统一整理为以下四类核心数据：

1. 设备主档：记录设备是什么。
2. 库存明细：记录设备当前属于哪个项目、位于哪个库位、还有多少数量。
3. 入库记录：记录什么时候、由谁、向哪个项目入库了多少设备。
4. 出库记录：记录什么时候、由谁、从哪个项目出库了多少设备以及具体用途。

系统同时需要满足以下能力：

- 同一设备在不同项目号下的库存可以分别管理。
- 库存汇总时合并同一设备的全部项目库存。
- 入库和出库支持按时间范围查询和统计总数。
- 库存管理支持按时间查询期初、期间变化和期末库存。
- 支持设备主档及库存初始化/盘点导入。
- 支持设备、库存、入库、出库和期间库存数据导出。
- 所有功能与现有扫码、审批、冻结、库存流水和权限体系保持一致。

## 2. 核心业务对象

### 2.1 设备主档

设备主档表示一种设备，是库存、扫码和入出库业务的基础资料。

### 2.2 项目库存明细

项目库存明细表示某种设备在指定项目号和库位下的实际库存。

一条库存明细的业务识别维度为：

```text
设备 + 项目号 + 库位
```

### 2.3 入出库业务事件

每次扫码入库、扫码出库以及审批后的实际库存变化都必须生成可审计的业务事件。

### 2.4 库存流水

库存流水是计算当前库存和历史库存的事实依据。入库、出库、盘点、导入调整和调拨都必须进入库存流水。

## 3. 设备主档需求

### 3.1 设备字段

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 设备ID | 是 | 设备业务唯一编码，可用于扫码、查询和导入匹配 |
| 设备名称 | 是 | 设备显示名称 |
| 品牌 | 否 | 设备品牌，支持查询和导入导出 |
| 设备分类 | 是 | 使用现有设备分类，不再设置独立的“类型”字段 |
| 型号 | 否 | 设备型号，支持查询和导入导出 |
| 单位 | 是 | 如台、套、个、米等 |
| 规格 | 否 | 设备规格信息 |
| 备注 | 否 | 设备长期备注 |

### 3.2 设备ID规则

- 设备ID复用现有 `Part.IPN` 字段。
- 设备ID不等于数据库自增主键。
- 设备ID在系统内必须唯一。
- 保存设备ID前去除首尾空格。
- 忽略大小写判断重复，例如 `DEV-001` 和 `dev-001` 视为同一个设备ID。
- 扫码、入库、出库、库存查询、导入和导出统一使用设备ID作为业务编码。

### 3.3 设备分类规则

- 不新增“类型”字段。
- 前端、查询条件、导入模板和导出文件统一使用“设备分类”。
- 设备分类复用现有分类树，允许父子层级。
- 支持按当前分类以及全部下级分类查询。
- 导入时设备分类必须匹配系统中已存在的分类。
- 默认不在导入过程中自动创建分类，避免产生重复分类和错别字分类。

## 4. 项目号需求

### 4.1 项目号定义

原系统中的“批次号”在本 WMS 业务中统一定义为“项目号”。

例如：

| 设备ID | 项目号 | 库存数量 |
| --- | --- | ---: |
| DEV-001 | XM-2026-001 | 10 |
| DEV-001 | XM-2026-002 | 20 |
| DEV-001 | XM-2026-003 | 5 |

库存汇总结果：

| 设备ID | 总库存 |
| --- | ---: |
| DEV-001 | 35 |

### 4.2 技术兼容要求

- 数据库内部继续使用现有 `StockItem.batch` 字段保存项目号。
- 不直接修改数据库列名，降低对 InvenTree 原生功能和后续升级的影响。
- WMS 前端、表单、筛选条件、详情、导入模板和导出文件统一显示“项目号”。
- API保留原 `batch` 字段兼容，并可向WMS前端提供 `project_number` 业务别名。
- 历史记录必须保存操作发生时的项目号快照，后续修改当前项目号时不能改变历史记录。

### 4.3 项目库存规则

- 一个设备可以同时属于多个项目。
- 同一个项目号可以包含多个不同设备。
- 同一个设备、同一个项目可以分布在多个库位。
- 库存明细按设备、项目号和库位区分。
- 库存汇总按设备合并全部项目号和纳入查询范围的库位。
- 新增入库时项目号必填。
- 出库时必须明确选择要扣减库存的项目号。
- 指定项目库存不足时，不允许自动扣减其他项目的库存。
- 历史空批次数据显示为“未归属项目”，并提供后续补录能力。

### 5.3 数量口径

- 当前库存：数据库中的实物库存数量。
- 冻结数量：已提交出库但尚未审批完成的占用数量。
- 可用数量：当前库存减去冻结数量及其他业务分配数量。
- 总库存：同一设备全部项目号、全部纳入查询范围的库位库存之和。
- 不新增独立的“总库存”数据库字段。
- 所有库存汇总都从库存明细实时计算，避免总库存和明细库存不一致。

### 5.4 库存筛选条件

库存汇总和库存明细支持以下筛选条件：

- 设备ID。
- 设备名称。
- 品牌。
- 设备分类。
- 型号。
- 项目号。
- 库位。
- 是否有库存。
- 是否有冻结库存。
- 时间范围。
- 关键字模糊搜索。

## 6. 库存按时间查询

### 6.1 查询定义

库存管理的时间查询采用“期间库存报表”口径，不只是筛选某段时间内最后更新过的库存行。

用户选择开始时间和结束时间后，系统展示：

| 字段 |
| --- |
| 设备ID |
| 设备名称 |
| 项目号 |
| 单位 |
| 期初库存 |
| 期间入库 |
| 期间出库 |
| 期间调整 |
| 期末库存 |

计算关系：

```text
期末库存 = 期初库存 + 期间入库 - 期间出库 + 期间调整
```

### 6.2 查询模式

- 按项目查看：每个设备、每个项目分别展示。
- 合并统计：同一设备的不同项目号合并展示。
- 只选择截止时间时，支持查询该时间点的历史库存。

### 6.3 时间选择

支持以下快捷时间和自定义查询：

- 今天。
- 昨天。
- 本周。
- 本月。
- 上月。
- 自定义开始时间和结束时间。

页面按中国时区显示和统计，数据库内部使用统一时间保存，避免跨天统计错误。

### 6.4 库存变化分类

期间库存中的变化分为：

- 入库：正式增加库存的业务操作。
- 出库：正式扣减库存的业务操作。
- 调整：盘点、库存导入和人工修正。
- 调拨：库位之间转移。

调拨规则：

- 同一项目不同库位之间调拨，不改变设备总库存。
- 按库位查询时，调拨会影响来源库位和目标库位库存。
- 项目号发生变化时必须记录变更流水，不能静默修改。

### 6.5 历史数据边界

- 为确保历史库存准确，库存流水必须保存结构化数量变化、项目号快照、库位快照和生效时间。
- 如果旧数据无法完整还原，则在新版上线时生成一次库存基准快照。
- 新版上线后的历史库存必须可以准确查询。
- 查询无法完整还原的旧日期时，页面需要提示“历史数据不完整”。

## 7. 入库管理

### 7.1 入库操作字段

| 字段 | 录入方式 |
| --- | --- |
| 设备ID | 扫码或手动输入 |
| 入库数量 | 手动输入，默认1 |
| 归属项目 | 选择或输入项目号 |
| 目标库位 | 选择或扫描库位 |
| 备注 | 选填 |

系统自动记录：

- 入库申请人。
- 扫码时间。
- 审批人。
- 审批时间。
- 正式入库时间。
- 入库前库存。
- 入库后库存。

### 7.2 入库记录字段

| 字段 |
| --- |
| 设备ID |
| 设备名称 |
| 入库数量 |
| 入库时间 |
| 入库人 |
| 归属项目 |
| 目标库位 |
| 备注 |
| 审批状态 |
| 审批人 |

### 7.3 入库业务规则

1. 根据设备ID查找设备主档。
2. 根据设备、项目号和目标库位查找库存明细。
3. 找到对应库存明细时增加数量。
4. 没有对应库存明细时创建新的项目库存明细。
5. 审批开启时，提交后只形成待入库记录，不立即增加库存。
6. 审批通过后才正式增加库存。
7. 审批拒绝、撤销或超时不增加库存。
8. 同一个请求重复提交不能重复增加库存。
9. 未知设备扫码入库时允许快速建档，但必须补齐必要的设备资料和项目号。
10. 入库数量必须大于零。

### 7.4 入库人员和时间口径

- 入库人：发起扫码或提交入库的人。
- 审批人：批准入库申请的人。
- 扫码时间：设备实际扫描或提交申请的时间。
- 入库时间：库存真正增加的时间。
- 审批模式下，入库时间为审批通过并成功落账的时间。

## 8. 出库管理

### 8.1 出库操作字段

| 字段 | 录入方式 |
| --- | --- |
| 设备ID | 扫码或手动输入 |
| 出库数量 | 手动输入，默认1 |
| 项目号 | 必须明确选择 |
| 来源库位 | 选择或扫描库位 |
| 用途 | 必填 |
| 备注 | 选填 |

系统自动记录：

- 出库申请人。
- 扫码时间。
- 审批人。
- 审批时间。
- 正式出库时间。
- 出库前库存。
- 出库后库存。

### 8.2 出库记录字段

| 字段 |
| --- |
| 设备ID |
| 设备名称 |
| 出库数量 |
| 出库时间 |
| 出库人 |
| 项目号 |
| 来源库位 |
| 用途 |
| 备注 |
| 审批状态 |
| 审批人 |

### 8.3 出库业务规则

1. 必须指定设备ID、项目号、来源库位和用途。
2. 只从指定项目、指定库位扣减库存。
3. 指定项目库存不足时直接提示，不自动借用其他项目库存。
4. 审批开启时，提交后先冻结对应库存。
5. 冻结后可用库存立即减少，但当前实物库存暂不减少。
6. 审批通过后正式扣减实物库存。
7. 审批拒绝、撤销或超时后释放冻结数量。
8. 多人同时出库时不能发生超卖。
9. 未知设备不允许直接出库。
10. 同一个请求重复提交不能重复扣减库存。

## 9. 入库和出库按时间统计

### 9.1 入库统计

选择开始时间和结束时间后显示：

- 入库记录数。
- 入库设备种类数。
- 入库总数量。
- 各设备入库小计。
- 各项目入库小计。

### 9.2 出库统计

选择开始时间和结束时间后显示：

- 出库记录数。
- 出库设备种类数。
- 出库总数量。
- 各设备出库小计。
- 各项目出库小计。
- 各用途出库小计。

### 9.3 统计规则

- 只统计成功且已经实际改变库存的记录。
- 待审批记录不计入总数。
- 冻结中的出库记录不计入出库总数。
- 审批失败、拒绝、撤销和超时记录不计入总数。
- 时间范围以正式入库时间和正式出库时间为准。
- 所有统计数字跟随当前筛选条件变化。
- 统计全部符合条件的数据，不只统计当前分页。
- 入库和出库支持分别查看。
- 综合统计可以同时显示期间入库、期间出库和库存净变化。

计算关系：

```text
期间净变化 = 入库总量 - 出库总量 + 库存调整量
```

### 9.4 入库统计筛选条件

- 时间范围。
- 设备ID或设备名称。
- 品牌。
- 设备分类。
- 型号。
- 项目号。
- 入库人。
- 目标库位。

### 9.5 出库统计筛选条件

- 时间范围。
- 设备ID或设备名称。
- 品牌。
- 设备分类。
- 型号。
- 项目号。
- 出库人。
- 来源库位。
- 用途。

### 9.6 不同单位的统计规则

不同单位的数量不能混合为一个总数。

示例：

```text
期间入库：120台、35套、500米
期间出库：30台、10套、120米
```

规则：

- 相同单位合计。
- 不同单位分别展示。
- 同一设备仍显示该设备自己的数量小计。
- 页面同时显示记录数，记录数不受单位影响。

## 10. 导入需求

本期仅提供以下导入功能：

- 设备主档导入。
- 库存初始化/盘点导入。
- 不提供入库记录导入。
- 不提供出库记录导入。

### 10.1 设备主档导入模板

```text
设备ID、设备名称、品牌、设备分类、型号、单位、规格、备注
```

设备主档导入规则：

- 设备ID不存在时新增设备。
- 设备ID已存在时显示更新预览。
- 用户确认后才更新已有设备。
- 重复设备ID必须报错。
- 未知设备分类必须报错。
- 空设备ID、空设备名称和空单位必须报错。
- 导入不得自动覆盖文件中未提供的已有字段。

### 10.2 库存导入模板

```text
设备ID、设备名称、品牌、设备分类、型号、单位、规格、项目号、库位、库存数量、库存日期、备注
```

每一行表示：

```text
某个设备 + 某个项目号 + 某个库位的实际库存
```

### 10.3 库存导入规则

- 导入前必须显示预览。
- 预览显示新增设备、新增库存明细、库存增加、库存减少、无变化和错误行。
- 已有库存按照盘点方式调整到导入数量。
- 库存数量不得为负数。
- 相同设备、项目号和库位的重复行必须报错。
- 设备不存在时，可以根据文件中的设备资料创建设备主档。
- 库存日期为空时使用导入完成时间。
- 导入操作保存操作人和导入时间。
- 保存调整前数量和调整后数量。
- 重复提交同一个导入任务不能重复调整库存。
- 库存导入记为“库存调整”，不计入入库总数或出库总数。
- 库存导入产生的调整必须进入库存历史查询。

## 11. 导出需求

### 11.1 设备主档导出

```text
设备ID、设备名称、品牌、设备分类、型号、单位、规格、备注
```

### 11.2 当前库存汇总导出

```text
设备ID、设备名称、品牌、设备分类、型号、单位、规格、总库存、冻结数量、可用数量、项目数量、备注
```

### 11.3 当前库存明细导出

```text
设备ID、设备名称、品牌、设备分类、型号、单位、规格、项目号、库位、当前库存、冻结数量、可用数量、最后变动时间、备注
```

### 11.4 期间库存导出

```text
设备ID、设备名称、项目号、单位、期初库存、期间入库、期间出库、期间调整、期末库存
```

### 11.5 入库记录导出

```text
设备ID、设备名称、入库数量、入库时间、入库人、归属项目、目标库位、备注、审批状态、审批人
```

### 11.6 出库记录导出

```text
设备ID、设备名称、出库数量、出库时间、出库人、项目号、来源库位、用途、备注、审批状态、审批人
```

### 11.7 导出通用规则

- 导出内容遵循页面当前筛选条件和时间范围。
- 导出全部匹配记录，不只导出当前分页。
- 导出统计结果必须和页面显示一致。
- 导出文件使用中文业务字段名。
- 导出时间按中国时区显示。

## 12. 权限与审计

### 12.1 权限要求

权限需要分别控制：

- 查看设备。
- 新增和编辑设备。
- 查看库存。
- 执行库存导入。
- 执行入库。
- 执行出库。
- 审批入库和出库。
- 查看全部库存操作记录。
- 导出数据。

### 12.2 审计要求

每次入库、出库和库存调整至少保存：

- 设备ID快照。
- 设备名称快照。
- 项目号快照。
- 库位快照。
- 操作类型。
- 请求数量。
- 实际数量。
- 操作前库存。
- 操作后库存。
- 发起人。
- 审批人。
- 扫码或申请时间。
- 正式生效时间。
- 用途。
- 备注。
- 成功、失败或待审批状态。
- 失败原因。
- 客户端请求唯一标识。

设备名称、项目号或人员资料后续发生变化时，不得影响历史记录展示。

## 13. 数据库调整范围

### 13.1 设备主档新增字段

- 品牌 `brand`。
- 型号 `model_number`。
- 规格 `specification`。

### 13.2 入出库事件新增字段

- 用途 `purpose`。
- 业务备注 `remark`。

### 13.3 库存流水增强字段

为支持历史库存查询，库存流水需要明确保存：

- 库存变化类型。
- 数量变化值。
- 变化前数量。
- 变化后数量。
- 项目号快照。
- 库位快照。
- 正式生效时间。

### 13.4 明确不新增的字段

- 不新增“类型”字段，统一使用设备分类。
- 不新增“总库存”字段。
- 不新增第二套库存余额。
- 不直接修改数据库中的原批次字段名。
- 不重复新增入库人、出库人、入库时间和出库时间，复用并规范现有操作人和完成时间字段。

## 14. 异常和边界场景

系统必须覆盖以下场景：

1. 同一设备属于多个项目时，设备汇总数量正确。
2. 同一设备、同一项目分布在多个库位时，汇总数量正确。
3. 项目A库存不足时不能自动扣除项目B库存。
4. 多人同时出库最后一件设备时只能有一个请求成功。
5. 已冻结库存不能被其他出库请求再次使用。
6. 待审批入库不能提前进入当前库存。
7. 待审批出库不能提前减少实物库存。
8. 审批拒绝、撤销或超时后正确释放冻结数量。
9. 重复扫码和网络重试不能重复增减库存。
10. 不同单位的数量不能混合成一个总数。
11. 库存导入中的重复行、非法数量和未知库位必须阻止提交。
12. 库存导入重复执行不能重复改变库存。
13. 零库存明细是否隐藏不能影响历史记录。
14. 设备删除或改名后，历史入出库记录仍然可以查询。
15. 历史空项目号数据显示为“未归属项目”。
16. 时间范围跨天、跨月时统计口径正确。
17. 同一请求只允许对应一种操作方向和一个审批状态流转。
18. 库存调拨不能错误计入入库总数或出库总数。

## 15. 验收示例

设备 `DEV-001` 在查询期间的数据如下：

| 项目号 | 期初库存 | 入库 | 出库 | 调整 | 期末库存 |
| --- | ---: | ---: | ---: | ---: | ---: |
| XM-A | 10 | 5 | 3 | 0 | 12 |
| XM-B | 20 | 2 | 4 | 1 | 19 |

按项目查看时：

- XM-A期末库存为12。
- XM-B期末库存为19。

合并统计时：

- 期初库存为30。
- 期间入库为7。
- 期间出库为7。
- 期间调整为1。
- 期末库存为31。

如果XM-A只有2个可用库存，申请从XM-A出库3个时必须失败，系统不能从XM-B自动补扣。

## 16. 验收标准

### 16.1 设备主档

- 可以录入、编辑、查询和导出全部设备字段。
- 不存在独立“类型”字段。
- 设备分类查询和导入匹配正确。
- 设备ID唯一性校验正确。

### 16.2 库存管理

- 库存汇总能正确合并不同项目号的库存。
- 库存明细能按项目号和库位准确展示。
- 当前库存、冻结数量和可用数量口径一致。
- 页面统计与导出数据一致。

### 16.3 时间查询

- 可以查询任意时间范围的期初、入库、出库、调整和期末库存。
- 只选择截止时间时可以查询截止时间点的历史库存。
- 待审批和失败业务不会进入实际入出库统计。
- 不同单位可以分别统计。

### 16.4 导入导出

- 设备和库存导入支持预览、校验和错误提示。
- 导入库存以调整方式记账，不计入入库或出库总数。
- 重复导入不会重复修改库存。
- 所有导出遵循页面筛选条件和时间范围。

### 16.5 审批与并发

- 入库审批通过前不增加库存。
- 出库审批通过前只冻结、不扣减实物库存。
- 拒绝、撤销和超时可以正确释放冻结。
- 并发操作不会导致重复入库或超卖。
