# Windows 本地标签打印设计

日期：2026-09-20

状态：交互与技术设计完成；本地打印组件接入尚未实现。当前部署已完成标签模板精简。

## 目标与范围

Windows 用户首次通过 WMS 下载并安装打印组件，设置随登录启动并完成信任设置。之后在 WMS 中读取本机打印机、保存选择、点击打印，不打开 PDF，不重复弹系统打印窗口。

首期支持商品详情、库存详情及相应列表的手动单张/批量商品 IPN 标签打印。保留 PDF 下载作为显式备用入口。不包含扫码后自动打印、手机本地打印或远程控制他人电脑。

## 用户操作

打印弹窗固定显示“商品 IPN 标签 · 50 × 30 mm”，不再要求选择业务模板；后端按 part/stockitem 解析对应模板，禁止前端硬编码数据库 ID。

未连接时显示：

```text
商品 IPN 标签 · 50 × 30 mm
打印组件未连接
[安装打印组件] [重新检测]
首次安装后，请允许组件随登录启动，并完成本站信任设置。
[下载 PDF]
```

检测失败不能直接认定未安装：可能是程序退出、浏览器权限、证书或端口问题。给出可区分的错误提示和重试入口，禁止提示用户关闭浏览器安全检查。

连接成功时显示：

```text
商品 IPN 标签 · 50 × 30 mm
本机打印组件：已连接
打印机：[本机打印机列表 ▼] [刷新]
每件份数：[1]
已选 3 件商品，共打印 3 张
记住此浏览器的打印机选择
[下载 PDF] [打印]
```

初次选择需用户明确确认，不自动向 Windows 默认办公打印机发送标签。旧设备消失或重命名时清空无效选择，要求重新选择，不自动切换另一台。更换电脑或浏览器需要重新选择。组件使用当前登录 Windows 用户会话运行，以读取该用户可见的网络共享打印队列。

## 技术方案

首选评估 QZ Tray Windows 版作为现成连接组件，WMS 自己提供交互，不自行重写设备驱动。组件选型以实际机型 PDF 打印、许可及信任部署验证为准；未购买或申请任何商业服务。

链路：WMS 前端 → 本机 QZ Tray 安全 WebSocket → Windows 打印队列/驱动 → 用户打印机。后端仅生成标签和对获准打印调用签名，不探测客户机硬件。

1. 前端集成连接管理，检测版本、连接状态，枚举打印队列。
2. 复用现有标签接口、权限检查、IPN 校验、份数和后台 PDF 生成。
3. 为标签输出监控增加受控的完成回调：本地打印模式接收文件，不执行 window.open；普通报告与 PDF 模式保持原行为。
4. 前端在当前用户权限下读取生成 PDF，转为组件支持的数据形式。不给组件传浏览器登录 Cookie，不要求组件访问受登录保护的文件 URL。
5. 配置目标队列、50 × 30 mm、实际大小，发送 PDF。现有后端已按份数展开页面，组件 copies 固定为 1，避免份数重复相乘。
6. 页面等待提交结果，显示“已提交到本机打印队列”。没有设备回执时不能显示“已经出纸”。

源码接入点：PrintingActions.tsx、UseDataOutput.tsx、lib/hooks/MonitorDataOutput.tsx、report/api.py，以及新增本地打印客户端封装、受权限控制的签名接口和安装说明页面。

## 静默打印与安装包

QZ 官方说明：消除重复确认需要受组件信任的证书和逐请求签名。正式部署可以评估官方签名证书服务或受控内部信任部署，不能将开发测试证书作为通用安装方案。费用与分发许可需在制作安装包前核对。

签名私钥只存服务端秘密配置，不进入前端、源码库或安装包。签名接口不能成为任意字符串签名接口：要求登录及打印权限，只接受允许的打印/枚举调用，校验任务归属、打印内容摘要、参数、时效和目标。不开放文件、串口、原始网络等无关能力。

网站 HTTPS、组件本地 WSS、打印消息签名是三个不同信任环节。当前 WMS 使用内部 CA，Windows 浏览器仍需信任网站证书，或后续替换为公开可信 HTTPS。

安装按钮应下载已验证版本的 Windows 官方安装程序，或在许可允许后分发封装安装包；显示版本、来源和校验信息。下载后由用户执行，不能声称网页可静默安装程序或自动绕过 Windows 安装提示。安装引导包含当前用户登录自启、首次信任、返回网页重新检测。现有官方安装流程能否达到一键引导，需 Windows 实机确认。

## 任务与故障处理

- 单次点击生成唯一任务标识，提交中禁用重复点击。组件连接失败时不发出打印任务。
- 生成失败：显示错误，允许重新生成；IPN 缺失：列出商品并阻止打印。
- 提交前断开：允许重新连接后发送。
- 提交后超时：标记“结果待确认”，要求检查打印队列，不自动重发。
- 明确补打：新建一次补打动作并记录关联任务、操作者、目标队列和份数。
- 保存任务状态及目标队列用于追溯；不把前端布尔锁当作断网或刷新后的防重保证。
- 纸张、缺纸、脱机状态能读到则展示；不能读取时明确仅获知队列提交结果。
- 退出 WMS 后取消尚未发送的前端流程；重新登录不能继续发送另一账号的待打印内容。

## 验收

1. 全新 Windows 安装 → 登录自启 → 返回 WMS 连接 → 枚举 → 选择 → 实际出纸。
2. 两台 Windows 电脑分别展示各自队列；同账号换电脑不会继承另一台的默认设备。
3. 单件多份、批量多件打印张数正确；PDF 模式和普通报告不回归。
4. 附件对应版式实际 50 × 30 mm，中文和二维码不裁切，扫描结果等于商品 IPN，扫码入出库可识别。
5. 拒绝信任、助手未启动、设备改名、缺纸、网络中断、连点、刷新、补打都有明确行为。
6. 未授权签名、跨账号任务、过期请求及无关组件调用被拒绝。
7. Windows 浏览器实测通过后才可宣称“本地直接打印已上线”。当前 macOS 开发环境无法代替此项。
